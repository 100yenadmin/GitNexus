# GitNexus 1.6.10-electric.10

`1.6.10-electric.10` is a narrow Electric Sheep release based on
`electric/v1.6.10-electric.9` at
`f3f86abf4b2a02fb2b754c95e18cb67a269505c8`. It corrects review identity,
skill synchronization, fork provenance, and bounded skill documentation
without merging the upstream release-candidate stream.

## Fixed

- PR review pins repository, base SHA, head SHA, merge base, worktree, and
  GitNexus index commit before treating graph evidence as current.
- Nine skills are authored under `.claude/skills/<skill>/SKILL.md` and copied
  byte-identically to npm-package, Claude-plugin, and Cursor distributions
  through `STANDARD_SKILL_CATALOG`.
- The existing analyze-time project installer remains limited to its six
  applicable workflow skills; those files are sourced from the synchronized
  npm copies. PR review, PDG, and taint skills remain global/plugin surfaces.
- The Electric plugin is skills/hooks-only. It no longer ships MCP launch
  configuration or an unqualified npm runtime reference.
- Package, plugin, and marketplace metadata identify the Electric fork and
  agree on `1.6.10-electric.10`.
- Impact, refactor, multi-repository, taint, PDG, CLI, and guide wording now
  matches the bounded runtime and side-effect contracts.

## Deferred

- Rename preview/apply remain separate recomputations rather than an immutable
  transaction. The skill documents this limitation; no rename API was changed.
- No upstream RC merge, reviewer swarm, skill-evolution framework, Render
  surface, npm publication, fleet reindex, or customer activation is included.

## Distribution

- Distribution remains a GitHub release tarball plus `SHA256SUMS`.
- Install the tarball into a versioned local prefix. Managed client
  configuration supplies
  `/Users/m1/Codex/bin/gitnexus-mcp-voyage-wrapper.sh mcp`.
- `1.6.10-electric.9` remains installed and available for immediate rollback.
